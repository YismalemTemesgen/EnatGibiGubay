# EnatGibiGubay (Student Voting App) 🗳️

**EnatGibiGubay** is a native Android application designed to facilitate secure, transparent, and efficient student union representative voting and election management.

---

## 🌟 Key Features

* **Dual Portal Access:** Separate login interfaces for **Students** and **Admins**.
* **Student Dashboard:** View voting options, cast votes securely, and view election updates.
* **Admin Management:** Manage candidate lists, track live election progress, and generate reports.
* **Modern UI:** Clean, intuitive interface built using Material Design 3 guidelines.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Java
* **IDE:** Android Studio / VS Code
* **Target OS:** Android (API level 21 and above)
* **Build System:** Gradle
